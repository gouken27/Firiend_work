# Академия света — Портал онлайн-курсов фотографии

Статичный многостраничный сайт по техническому заданию «ФотоСтарт».  
Целевая аудитория: школьники и студенты 14–25 лет, желающие освоить фотографию с нуля.  
Концепция: путь «**Было → Стало**» — ученик с нулевым уровнем доходит до профессиональных снимков.

## Страницы сайта

### Главная (index.html) — ТЗ §4.1
- **Герой-секция**: заголовок и подзаголовок из `data/main.json`
- **Слайдер «Примеры работ»**: Swiper с эффектом coverflow, адаптивный (1/2/2.8 слайда)
- **Преподаватели**: карточки с аватаром и именем из `data/main.json`
- **Форма обратной связи**: имя, email, сообщение — обработчик-заглушка (alert)

### Дашборд (pages/dashboard.html) — ТЗ §4.2
- Публичная активность платформы: количество курсов, студентов, часов обучения
- Данные из `data/dashboard.json`

### Курсы (pages/courses.html) — ТЗ §4.3
- CSS Grid-каталог карточек с обложкой, описанием, ценой и кнопкой «Подробнее»
- Данные из `data/courses.json`

### Профиль (pages/profile.html) — ТЗ §4.4
- Аватар и имя пользователя из `data/user.json`
- Кнопка «Редактировать» открывает нативный `<dialog>` с формой
- Кнопка «Выход» возвращает на главную страницу
- Форма регистрации нового пользователя (заглушка)

- ✅ **Дашборд** — статистика платформы в карточках
- ✅ **Курсы** — адаптивная CSS Grid-сетка карточек с ценами

## Технологии — ТЗ §5

| Технология | Назначение |
|---|---|
| HTML5 | Структура страниц; нативный `<dialog>` для модальных окон |
| CSS3 | Стили: Flexbox, CSS Grid, `position: sticky`, `@media` |
| JavaScript ES6+ | Модули (`import`/`export`), `fetch`, `Promise.all` |
| Swiper 11 (CDN) | Слайдер главной страницы с эффектом coverflow |

Фреймворки (Bootstrap, Vue, React) **не используются** — только нативный стек.

## Архитектурные решения

- **Компонентный подход**: шапка и футер — отдельные HTML-фрагменты (`pages/header.html`, `pages/footer.html`), загружаемые через `loadHTML()` и вставляемые в placeholder-теги `<header id="header">` / `<footer id="footer">` на каждой странице.
- **Данные в JSON**: весь контент (тексты, курсы, навигация, пользователь) хранится в `data/*.json` и загружается через `loadJSON()`. Смена контента — только через JSON, без правки HTML/JS.
- **ROOT-префикс**: каждый JS-модуль принимает константу `ROOT` (`''` для корня, `'..'` для `/pages/`), чтобы пути к ресурсам работали на любой странице.
- **`{ROOT}` в nav.json**: шаблонная метка в href-ах навигации, заменяемая реальным префиксом в `header.js` — единый список ссылок для всех страниц.
- **z-index**: шапка и футер `z-index: 10`; нативный `<dialog>` перекрывает их автоматически.

## Дизайн — ТЗ §6

- Нейтральная светлая схема с тёмными акцентами (`#222`) — характерно для фотопортфолио
- Крупная типографика заголовков
- Hover-эффекты на всех интерактивных элементах (кнопки, ссылки, карточки)
- Адаптивность: мобилки (`≤640px`), планшеты, десктоп

## SEO — ТЗ §7

Каждая страница содержит:
- `<title>` — уникальный заголовок
- `<meta charset="UTF-8">` и `<meta name="viewport">` — обязательная основа
- Фавикон из `data/media/logo.png`

## Запуск

1. Откройте `index.html` в браузере **через локальный сервер** (например, Live Server в VS Code)  
   ⚠️ Прямое открытие файла через `file://` блокирует `fetch()` из-за CORS — сайт не загрузит JSON и HTML-фрагменты.
2. Переходите по страницам через навигацию в шапке.
