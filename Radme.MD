# Фотограф мечты - Портал курсов

Статичный веб-сайт портала онлайн-курсов по фотографии и фотошопу.

## Структура проекта

```
index.html                    # Главная страница
src/
├── css/                     # Стили
│   ├── index.css           # Главный файл импорта
│   ├── header.css          # Стили хедера и навигации
│   ├── main.css            # Стили главной страницы
│   ├── profile.css         # Стили профиля
│   ├── dashboard.css       # Стили дашборда
│   ├── course.css          # Стили страницы курсов
│   ├── courses_all.css     # Дополнительные стили
│   └── modals.css          # Стили модальных окон
├── js/                     # JavaScript модули
│   ├── header.js           # Хедер и навигация
│   ├── main.js             # Главная страница со слайдером
│   ├── users.js            # Профиль, регистрация, редактирование
│   ├── dashboard.js        # Дашборд со статистикой
│   ├── course.js           # Каталог курсов
│   ├── modal.js            # Утилиты модалей
│   └── index.js            # Экспорты всех модулей
├── data/
│   ├── profiles.json       # Данные пользователя (JSON)
│   ├── pakage.json         # Метаданные
│   └── media/              # Изображения
└── Pages/                  # HTML страницы
    ├── profile.html        # Профиль пользователя
    ├── dashboard.html      # Дашборд
    ├── course.html         # Курсы
    ├── courses/            # Отдельные курсы
    └── modals/             # Модальные окна
```

## Функционал

- ✅ **Главная страница** - герой, слайдер примеров работ, преподаватели, форма обратной связи
- ✅ **Навигация** - меню на десктопе, бургер-меню на мобильных
- ✅ **Профиль** - просмотр профиля, редактирование имени, форма регистрации
- ✅ **Дашборд** - статистика (курсы, студенты, часы обучения)
- ✅ **Курсы** - каталог всех доступных курсов с ценами
- ✅ **Модальные окна** - редактирование профиля, уведомления

## Технологии

- HTML5
- CSS3 (без фреймворков)
- JavaScript (ES6 модули, без библиотек)
- JSON для хранения данных

## Ключевые моменты

- **Простой слайдер** - карточки двигаются в маленьком контейнере (без Swiper)
- **Легкий код** - минимум логики, только необходимое
- **Z-index правильно** - хедер: 100, модали: 999-1000
- **Адаптивный дизайн** - поддержка мобильных и десктопов
- **JSON only** - сайт работает только с JSON данными из `profiles.json`

## Использование

1. Откройте `index.html` в браузере
2. Используйте навигацию для перемещения по страницам
3. На профиле можно редактировать данные и регистрироваться
