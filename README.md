# Академия света — портал онлайн-курсов фотографии

Статичный многостраничный сайт. Целевая аудитория: школьники и студенты 14–25 лет.
Концепция: путь «Было → Стало» — от нуля до профессиональных снимков.

## Структура

```
index.html              # Главная: герой, слайдер, преподаватели, форма
pages/
├── courses.html        # Каталог курсов
├── dashboard.html      # Дашборд: часы, календарь, статистика, графики
└── profile.html        # Профиль: карточка, модалка, форма регистрации
css/
├── base.css            # Переменные, сброс, типографика
├── layout.css          # Шапка, подвал, main, адаптив
├── components.css      # Кнопки, формы, диалог, слайдер
└── pages.css           # Стили секций страниц
js/
├── theme.js            # Переключатель тёмной темы (на всех страницах)
├── menu.js             # Мобильное бургер-меню (на всех страницах)
├── main.js             # Слайдер Swiper + форма обратной связи
├── dashboard.js        # Живые часы и календарь текущего месяца
└── profile.js          # Модалка редактирования, регистрация, выход
media/                  # Изображения (логотип, аватар, курсы, преподаватели)
```

## Принципы

- **Весь видимый контент — прямо в HTML.** Никакого fetch, JSON или динамического рендера. Что видно на странице, то и написано в разметке.
- **JS только для интерактива:** слайдер, тема, меню, формы, часы.
- **Относительные пути:** на главной — `media/...`, на страницах в `pages/` — `../media/...`. Работает и двойным кликом, и в Live Server, и на GitHub Pages.
- **CSS без повторов:** общие свойства описаны один раз, специфика — в классах. Тёмная тема — через переопределение CSS-переменных в `html.dark`.
- **Никаких проверок и try/catch** — код рассчитан на корректную разметку.

## Запуск

Откройте `index.html` — двойным кликом, через Live Server или на GitHub Pages. Сервер не обязателен.

## Технологии

HTML5 (нативный `<dialog>`), CSS3 (Flexbox, Grid, `position: sticky`, `@media`),
JavaScript (обычные скрипты, без модулей), Swiper 11 (CDN) — слайдер с эффектом coverflow.
